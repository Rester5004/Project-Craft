## 기계 플레이스홀더 → 실제 기계 아이템

- 레시피 14개에서 참조 16건 치환

- `감별기` → `Machine:Appraiser` (`Assets/Prefabs/Items/Placeholder/감별기.asset` 삭제)
- `마나 용해기` → `Machine:ManaDissolver` (`Assets/Prefabs/Items/Placeholder/마나 용해기.asset` 삭제)
- `마법부여기` → `Machine:Enchanter` (`Assets/Prefabs/Items/Placeholder/마법부여기.asset` 삭제)
- `압연기` → `Machine:RollingMill` (`Assets/Prefabs/Items/Placeholder/압연기.asset` 삭제)
- `정밀 세공기` → `Machine:PrecisionLathe` (`Assets/Prefabs/Items/Placeholder/정밀 세공기.asset` 삭제)
- `중급 재단` → `Machine:IntermediateAltar` (`Assets/Prefabs/Items/Placeholder/중급 재단.asset` 삭제)
- `초급 재단` → `Machine:BasicAltar` (`Assets/Prefabs/Items/Placeholder/초급 재단.asset` 삭제)
- `화력 발전기` → `Machine:ThermalGenerator` (`Assets/Prefabs/Items/Placeholder/화력 발전기.asset` 삭제)

- 삭제한 플레이스홀더 8개

- 새로 만든 기계 0종 · 연결한 레시피 0개

## 코어 조합기 레시피의 티어 분포

조합대 티어는 현재 **0** 이라, 그보다 높은 티어의 레시피는 등록은 되지만 목록에 뜨지 않는다.

- 티어 0 : 40개  ← 지금 보임
- 티어 1 : 35개
- 티어 2 : 22개
- (산출물이 없어 등록 제외: 8개)
